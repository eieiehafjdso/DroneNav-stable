# 参数与用法（RMUC 2025 场地 → MuJoCo）

目录：`src/mujoco_sim`

## 1. 文件清单

| 文件 | 作用 |
|---|---|
| `build.sh` | **一键重新生成** `rmuc_2025_field.xml`（推荐只记这一条命令） |
| `launch/view_only.sh` | 用 NVIDIA 独显打开 viewer |
| `view.py` | viewer 本体，支持 `--blink` 让中心灯闪烁 |
| `sdf2mjcf.py` | SDF→MJCF 转换器（所有参数的真正实现） |
| `rmuc_2025_field.xml` | 生成的成品（4383 个碰撞 box + 贴图 + 单灯） |
| `assets/field_floor.png` | 场地地胶贴图（程序生成，可替换） |
| `meshes/rmuc_2025_uv.obj` | 带 UV、未合并顶点的场地网格（25 MB） |

## 2. 最短路径

```bash
cd src/mujoco_sim

./build.sh                 # 生成
./launch/view_only.sh              # 看
./launch/view_only.sh --blink 3    # 看（中心灯每 3 秒亮灭）
```

两个脚本都自己找 venv 的 python，**不需要先 activate**。

## 3. build.sh 的快捷变量

| 变量 | 默认 | 含义 |
|---|---|---|
| `SUN_P` | `0.0` | 太阳光亮度倍率（0 = 只有中心灯） |
| `LAMP_H` | `9` | 中心灯挂高（米） |
| `LAMP_P` | `1.0` | 中心灯亮度 |
| `TEAM_P` | `0.35` | 红/蓝方氛围灯亮度（0 = 关） |
| `CHECKER` | `1.0` | 场地外棋盘格边长（米） |
| `RES` | `0.05` | 碰撞栅格精度（米），越大越快 |
| `WORLD` | `~/one_drone/worlds/rmuc_2025_3m_vio_columns.sdf` | 源世界文件 |
| `SEARCH_DIR` | `~/one_drone/worlds/models` | `model://` 资源目录 |
| `OUT` | `rmuc_2025_field.xml` | 输出文件名 |

例：

```bash
SUN_P=0.3 LAMP_P=1.2 ./build.sh
RES=0.10 ./build.sh                 # 粗一半，生成更快
CHECKER=2.0 ./build.sh              # 格子 2 m
OUT=test.xml ./build.sh             # 输出到 test.xml
./build.sh --spot-shadows           # 额外参数透传给转换器
```

## 4. sdf2mjcf.py 全部参数

```bash
python sdf2mjcf.py <world.sdf> -o <out.xml> [选项...]
```

### 4.1 必填

| 参数 | 说明 |
|---|---|
| `world` | 源 SDF 世界文件路径（位置参数） |
| `-o, --output` | 输出 MJCF 路径，**必填** |

### 4.2 资源与几何

| 参数 | 默认 | 说明 |
|---|---|---|
| `--search DIR` | 世界文件所在目录 | `model://` 搜索路径，可写多次 |
| `--meshdir DIR` | `meshes` | 网格输出目录（相对输出文件） |
| `--exclude NAME` | 无 | 按名字丢弃某个 model / include，可写多次 |
| `--floor` | 关 | 按网格包围盒自动补一块地面平面 |
| `--mesh-collision {none,hull}` | `none` | `hull` 让网格参与碰撞（大网格会变实心块，慎用） |

### 4.3 外观

| 参数 | 默认 | 说明 |
|---|---|---|
| `--texture PNG` | 无 | 给网格铺平面投影纹理（STL 无 UV，会自动转带 `vt` 的 OBJ） |
| `--checker-ground M` | `0`（关） | 场地外用黑白棋盘格地面，参数为格子边长（米） |
| `--dark-sky` | 关 | 深蓝渐变天空 |
| `--arena-lights N` | `0` | 场地四周加 N 盏聚光灯（冷暖交替） |
| `--arena-light-power P` | `0.32` | 每盏围灯亮度 |
| `--team-lights P` | `0`（关） | 红/蓝方各一盏低位点光，模拟队伍色氛围光 |
| `--center-light H` | `0`（关） | 场地正中高度 H 处一盏向下聚光灯，并生成可见灯球 |
| `--center-light-power P` | `1.0` | 中心灯亮度 |
| `--sun-power S` | `1.0` | 方向光（太阳）倍率，`0` 等于关掉 |
| `--shadowsize N` | `2048` | 阴影贴图分辨率（8192 会很卡） |
| `--spot-shadows` | 关 | 让聚光灯也投影（默认只有太阳投影） |
| `--fog` | 关 | 体积雾（30–120 m），做 SLAM 干扰时用 |

### 4.4 碰撞

| 参数 | 默认 | 说明 |
|---|---|---|
| `--collision {none,boxes}` | `none` | `boxes` = 把场地网格切成实体 box 碰撞体 |
| `--collision-res M` | `0.10` | 切 box 的栅格精度（米）。`0.05` → 4383 个 box，`0.10` → 1942 个 |

碰撞体上写入的接触参数：

```
condim=3  friction="0.9 0.008 0.0001"
solref="0.004 1"  solimp="0.9 0.95 0.001"
<option timestep="0.002" cone="elliptic" impratio="8"/>
```

## 5. view.py 参数

```bash
python view.py [xml] [--blink SEC] [--light NAME] [--ball NAME]
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `xml` | `rmuc_2025_field.xml` | 要打开的世界 |
| `--blink SEC` | `0`（常亮） | 中心灯亮/灭周期（秒） |
| `--light NAME` | `center_lamp` | 要控制的灯 |
| `--ball NAME` | `center_lamp_ball` | 灯球 geom 名（灭灯时一起变暗） |

MuJoCo 的 XML 是静态资源，没有动画；闪烁是在 `view.py` 的循环里改
`light_diffuse` / `mat_emission` / `geom_rgba` 实现的。

## 6. 常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| `the following arguments are required: -o/--output` | 命令里没写 `-o 文件名`；或 `...` 被当成路径 | 用 `./build.sh`，别手打带 `...` 的命令 |
| `SyntaxError: invalid syntax` 出现在 f-string 行 | 裸 `python` 是 Python 2.7 | `source /data/MuJoCo/MuJoCo-drones-gym/.venv/bin/activate`，或用 `./launch/view_only.sh` |
| `prime-run：未找到命令` | 本机没装 `prime-run` | 用 `./launch/view_only.sh`（内部设 `__NV_PRIME_RENDER_OFFLOAD=1`） |
| 模型看起来"融化"/糊在一起 | OBJ 顶点被合并 → MuJoCo 用平滑法线 | 已修：导出前 `unmerge_vertices()`，顶点数 = 面数×3 |
| 撞墙穿过去 | 网格只做显示，碰撞只有地面 | 加 `--collision boxes` |
| 帧率低 | 核显渲染 / 阴影过大 | `./launch/view_only.sh` 走独显；`--shadowsize 1024` |

## 9. 赛场配色（style v2）

参照真实赛场照：深灰地胶 + 红蓝半场 + 近黑墙体 + 暗背景 + 队伍色氛围光。

| 项 | 值 | 说明 |
|---|---|---|
| 贴图底色 | 0.36 灰 + 拼板缝 | 深灰金属地胶 |
| floor_red | rgba `1.0 0.58 0.55` | 乘在贴图上 → 反照率 ≈ (0.36, 0.21, 0.20) |
| floor_blue | rgba `0.58 0.68 1.0` | ≈ (0.21, 0.24, 0.36) |
| wall | rgba `0.78 0.78 0.80` | ≈ 0.28 灰 |
| slope | rgba `0.90 0.90 0.92` | ≈ 0.32 灰 |
| 天空 | `0.02 0.03 0.05 → 0.07 0.09 0.14` | 近黑 |
| 场外棋盘 | `0.05` / `0.62` | 压暗 |
| 主灯 | spot (0,0,9)，diffuse 1.6，cutoff 85°，exponent 0.8 | 单灯照明 |
| 环境光 | headlight ambient 0.45 / diffuse 0.40 | 提亮暗部 |
| 氛围灯 | team_red(0,-11,1.2)、team_blue(0,11,1.2)，0.30 | 队伍色 |

**关键教训**：MuJoCo 的 material `rgba` 是**乘**在贴图上，不是替换。
上一版用 `0.46 0.20 0.20` 去乘 0.22 的贴图，反照率只剩 0.10，所以黑成一片；
现在 tint 接近 1.0，靠贴图本身提供明度。

## 10. 无人机 x500（等 PX4 接入，无控制器）

### 生成

```bash
python build_x500.py            # x500.xml             无人机 + 空地
python build_x500.py --merge    # rmuc_2025_drone.xml  无人机 + 场地
```

只读 `/data/DroneNav/PX4-Autopilot/.../x500_base`，不改 PX4 目录。

### 当前状态

- 出生点 (1.3, 9.4, 0.25)，落到场地地面 z=0.20，静置 5 s 接触 4 点、速度 0；
- 4 个旋翼有 `<velocity>` 执行器（`ctrlrange 0–1000`），**ctrl 全 0，不转**，留给 PX4 输出；
- 机体：PX4 原始 179k 面网格，质量 2.0 kg + 4×0.0161 kg，惯量取自 SDF；
- 场地：4383 个碰撞 box（5 cm 栅格）。

### 看静态模型

```bash
./launch/view_only.sh rmuc_2025_drone.xml
```

空格暂停后 `Ctrl+右键` 可拖动飞机。

### 网格对齐（数值核对）

SDF 里的 visual pose/scale 已**烘焙进顶点**，避免 MuJoCo 重心补偿导致二次偏移：

| 部件 | 处理 |
|---|---|
| 机体外壳 | 绕 z 180° + 上移 0.025 m |
| 桨叶 | 缩放 0.846 + 偏移 (-0.022, -0.146, -0.016) |
| 电机座 | 下移 0.032 m |

实测四个桨中心与旋翼轴 x/y 误差 < 1 mm，z 全部 0.294–0.319，压在电机（0.28–0.30）上。

### 电机模型

- `motor_model.py`：`F=KF·ω²`、反扭矩 `KM·ω²`、旋翼位置/旋向；
- `view.py` 每步调用它；PX4 桥接后同样由它把 `HIL_ACTUATOR_CONTROLS` 转成推力。

## 11. PX4 SITL 接入

物理已改为 **PX4 进程内的 `mujoco_bridge` 模块**（源码在 `../mujoco_bridge_px4/`，
已装进 PX4 的 `src/modules/simulation/mujoco_bridge/`），不再是外部 `px4_bridge.py`。

### 数据流

```
PX4 进程内：
  mujoco_bridge 模块（PX4_SIMULATOR=mujoco 时由 px4-rc.mujoco 启动）
     ├─ 加载 MuJoCo 世界（MUJOCO_MODEL 指定）
     ├─ 读 actuator_motors（4 路 0~1）→ 转速 ×1000 → F=KF·ω² 施加到 MuJoCo
     ├─ 发 uORB：sensor_accel/gyro(250Hz) + baro/mag/gps + vehicle_visual_odometry
     └─ px4_clock_settime 推进时钟（1× 实时，PX4_SIM_SPEED_FACTOR 可加速）
```

### 运行步骤

```bash
# 一条命令：Agent + PX4（PX4 内起 MuJoCo）
ros2 launch mujoco_sim rmuc_sim.launch.py

# 或手动分开
MicroXRCEAgent udp4 -p 8888
PX4_SIMULATOR=mujoco PX4_SYS_AUTOSTART=10016 \
  MUJOCO_MODEL=/data/DroneNav/src/mujoco_sim/rmuc_2025_drone.xml \
  ./bin/px4 -s etc/init.d-posix/rcS
```

PX4 侧需一次性：`param set UXRCE_DDS_SYNCT 0; param set EKF2_EV_CTRL 15; param save`。

### 实现要点

| 项 | 处理 |
|---|---|
| 仿真速率 | `dt=0.002`（物理 500Hz），每 2 步发一次 IMU（250Hz） |
| 传感器 | 比力 `R^T(a - g)`、机体系角速度、气压高度；**已做 FLU→FRD 转换** |
| 执行器 | `actuator_motors.control[0:4]`（0–1）× 1000 → 电机转速 |
| 推进 | 推力按 `KF·ω²` 施加（在 `mujoco_bridge` 的 `apply_thrust`），`mj_step` 推物理 |
| 画面 | 进程内模块暂为无头运行；看模型用 `./launch/view_only.sh` |

> `motor_model.py` / `view.py` 保留用于**独立查看器**（拖电机滑块自测推力模型），
> 不和 PX4 内 MuJoCo 状态同步。
